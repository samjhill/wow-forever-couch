# PvP controller notes (Warlock / Rogue / Mage)

Separate character from the Tauren Bear + Ashley Hunter duo. Focus: BGs and duels.

## Shared PvP priorities

- Fast target swap (LB / trackpad click)
- Interrupt on RT or B
- One major defensive on D-pad
- CC on modifier+face
- Camera + kiting on sticks/pads
- Focus target if Forever/ConsolePort exposes it

## Warlock (primary PvP candidate)

| Input | Action theme |
|-------|----------------|
| A | Shadow Bolt / filler |
| X | Affliction DoT / instant |
| Y | AoE / Seed |
| B | Fear / CC |
| RT | Spell Lock / interrupt (Felhunter) |
| LT | Healthstone / defensive
| D-pad | Pet attack / follow / defensive CD / racial |
| RB+face | Curses / banishes |

Pet commands must stay on the pad — no keyboard pet bar.

## Rogue (alt)

| Theme | Binding idea |
|-------|----------------|
| Openers | Stealth chord + Ambush/Cheap Shot on face |
| Interrupts | Kick on RT |
| Escape | Sprint / Vanish on D-pad |
| Control | Blind / Gouge on modifier |

## Frost Mage (alt)

| Theme | Binding idea |
|-------|----------------|
| Root/snare | Frost Nova / Cone on LT/Y |
| Interrupt | Counterspell on RT |
| Escape | Blink / Ice Block on D-pad |
| Burst | Icy Veins + deep freeze analogues on RB+face |

## Steam Controller

Use right-pad radial for trampling utility (trinket, racial, badge) so face buttons stay combat-pure.
