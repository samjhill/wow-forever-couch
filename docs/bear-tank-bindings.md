# Bear tank bindings (Tauren Guardian / Bear)

Draft for **WoW: Forever** level-together content. Verify ability names on the Blizzard gamepad bar in-game — Forever may rename or rebalance the Classic-era bear toolkit.

## Design goals

- Move while attacking
- Fast target acquire / swap
- Instant taunt
- ST threat + AoE threat
- Defensives + interrupt
- Form swap / travel escape
- Marks for Ashley (Hunter) pulls

## Conceptual gamepad face + bumpers

| Input | Priority | Intended action (Classic-era analogues) |
|-------|----------|----------------------------------------|
| A | Highest | Maul / primary threat spender |
| X | High | Mangle / secondary ST |
| Y | High | Swipe / Thrash AoE threat |
| B | Highest | Growl (taunt) |
| LB | High | Target nearest enemy / cycle |
| RB | Hold | Modifier layer |
| LT | Medium | Demoralizing Roar / AoE utility |
| RT | Medium | Bash interrupt / Bash-like CC |
| D-pad U | High | Frenzied Regeneration / self-heal CD |
| D-pad L | High | Survival Instincts / major defensive |
| D-pad R | Medium | Enrage / rage gen |
| D-pad D | Medium | Barkskin / secondary defensive |
| RB+A | Medium | Skull mark |
| RB+X | Medium | Moonfire / Faerie Fire (threat/utility) |
| RB+Y | Medium | Challenging Roar (AoE taunt when available) |
| RB+B | High | Cancel form / humanoid interact / mount form |
| Select | — | Game menu |
| Start | — | Map |

## Steam Controller extras

| Input | Action |
|-------|--------|
| Left grip | Push-to-talk dictation start/stop (see voice-dictation) |
| Right grip | Modifier (same as RB) or focus target |
| Right pad click | Sticky camera center |

## Verification checklist (in-game)

- [ ] Continuous kite/strafe while pressing A/X
- [ ] Growl reachable without releasing movement
- [ ] AoE threat on 3+ without menu
- [ ] Interrupt on demand
- [ ] Defensive within one d-pad press
- [ ] Form swap to loot/gossip without keyboard
- [ ] Ashley can see skull marks

## Notes

Revisit at 20 / 40 / 60 when new abilities unlock. Prefer emergency buttons over rarely used utility.
